# 高级功能：按需选择，独立验收

[目录](tutorial.md) · [能力映射](core-logic.md)

完整源模块包含本地主线以外的功能。这些文件已保留，便于审查和后续扩展；它们的安装与运行不由打开本地检测界面触发。

## CLIProxyAPI：独立的 API 转发服务

它用于另外选择的 API 工作流，不是 Claude 检测的依赖，也不改善住宅出口的属性。**本项目不提供将 Claude 消费订阅账号的登录态或 OAuth 凭据接入此服务的教程。** 其他服务的凭据也须按其当时有效的条款和授权方式使用。

在明确选择完整服务栈，并已完成网络阶段后，模块现有命令为：

```bash
bash "$VPS_REMOTE" my-vps cliproxy
bash "$VPS_REMOTE" my-vps maint
bash "$VPS_REMOTE" my-vps verify --full
bash "$VPS_REMOTE" my-vps save --lang zh
```

`VPS_REMOTE` 是[网络章](03-network-setup.md)定义的本地脚本路径。不要先取消防火墙限制再安装：先确认管理方式、认证和访问来源，再决定 API 端口是否需要公网开放。曾安装纯网络维护定时器的，先消除重复任务，不同时启用两套备份 / 规则刷新任务。

服务以独立 `cliproxy` 系统用户运行，监听回环地址 `127.0.0.1:8317`，由 Nginx 提供 HTTPS 入口；配置和凭据设为仅授权用户可读。管理 Key 与调用 Key 分开生成。空实例不包含任何上游账号，选择提供商和授权属于另外一步。

## 事务式自动更新

完整维护模块保留了这些逻辑：

1. 查询稳定版本并下载，核对校验值。
2. 等待连续两次没有在途请求，再替换；长时间一直忙时存在最长等待策略，须了解其影响。
3. 保存旧二进制和配置，原子替换，重启服务。
4. 检查本地与公网健康；失败自动恢复旧版本，暂时避开同一失败版本。
5. 用文件锁防止并发更新，日志避免打印凭据；管理页面单独更新。

该机制尽量减少中断，不等于所有请求都无感。校验值与下载来自同一供应链时，不能证明维护者账号或发行系统未被攻陷。3x-ui / Xray 不在这套自动追新流程中。

## 订阅、规则和流量统计

订阅服务在 3x-ui 前加入路径白名单、格式转换 / 模板、流量显示和规则镜像。客户端从你自己的服务器取规则；刷新失败保留上一份。

流量统计支持按双向 / 入站 / 出站 / 取大值统计，用订单真实额度和重置日校准。保留的 `traffic` 子命令可以设置已用量；特定服务商的 KiwiVM 适配可通过独立 API Key 获取后台读数，属于明确选择的高级接入。它不意味着本项目推荐该服务商，也不应把其 Key 写进聊天或仓库。

`save` 导出的交付文件包含订阅、面板和 API 凭据，只能保存在本地私有位置。它按完整服务栈编写；纯网络方案由操作者导出必要字段并注明 API 未部署，不能伪造一份“全部已验收”的交付记录。

## 上游切换器模块

| 功能 | 入口 | 使用边界 |
|---|---|---|
| macOS 原生界面与菜单栏 | `modules/switcher/app/main.swift` | 需编译及平台验证，原生安装器可能注册服务和修改设置 |
| Windows WPF 界面与核心 | `modules/switcher/windows/` | Beta 模块，安装器可能修改时区、IPv6 和计划任务 |
| Linux 菜单和核心 | `modules/switcher/linux/` | 面向浏览器身份，具体环境支持按模块说明核对 |
| 多账号快照 A–D | 核心 `switch` 与账号归档逻辑 | 整体移动 / 克隆登录态，须另行授权并保护原始数据 |
| 跨身份保留 | `keep-in-workspace.txt` 相关逻辑 | 默认关闭，不共享凭据、设备标识或账号专属状态 |
| 加密快照导出 / 导入 | macOS `snapshot-export` / `snapshot-import` | AES-256 镜像，需要自存口令；本地快照不保证服务端会话仍有效 |
| 进程守护 | `daemons/`、Windows / Linux bodyguard | 有轮询窗口，不能当防火墙级零泄漏保证 |
| 配置漂移修复 | watchdog / `fix` | 会改变配置，执行前给出差异和恢复方法 |
| 独立代理诊断 | macOS `diagnose-proxy` | 只验证固定地址传输，不等于登录可用或启动许可 |
| 一次性浏览器 | macOS `open-safe` | 临时 profile 不继承日常登录，结束后清理；不是匿名保证 |
| CLI 路径体检 | macOS `cli-info` | 只读检查安装路径与版本，不自动卸载 |
| 设备 / 浏览器信息 | `fingerprint`、`modules/switcher/docs/` | 信息展示，不能推断平台实际风控规则或概率 |

保留模块不等于新工作台已经实现这些功能。首次选择安装前，阅读对应模块说明，列明修改范围，先保存登录态及用户现有配置。

## Web 检测页与静态网站

`modules/switcher/docs/` 保留浏览器检测页；它受浏览器权限和网络模型限制，不能检查本机 TUN、进程和防火墙。其网络行为与新工作台不同，应先阅读模块自己的隐私说明。

`modules/vps/site/` 保留完整网站源码、中文 / 英文教程、How-to、FAQ 和素材。公开仓库不代表 GitHub Pages 已部署；构建和发布应另行核验路径、链接与真实可访问页面。

模块中历史路线图、设计稿、静态测试和旧运行样本只说明来源与历史状态，不自动成为本项目已完成的功能或真机验证证据。
