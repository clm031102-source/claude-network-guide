# 04 本机自动体检

[目录](tutorial.md) · [上一章](03-network-setup.md) · [下一章 逐项验收](validation.md)

**打开 Claude 本机体检，直接等待结果。** 程序自动识别电脑里的网络与客户端配置；不要求先填写住宅 IP、代理端口或安装路径，也不把未勾采购声明判为失败。

## 打开程序

Windows 用户下载[本地程序便携包](desktop-app.md)，解压后双击 `ClaudeNetworkGuide.exe`，无需安装 Python。独立窗口打开后自动检测一次；关闭窗口即关闭自己的本机服务。

维护者或 macOS / Linux 用户也可从源码运行：Python 3.10+，在仓库根目录执行 `python -m app.server`（部分系统为 `python3`），Windows 也可双击 `启动检测.cmd`。源码版会打开本地网页，默认 8765–8774 选择可用端口；桌面版使用空闲回环端口。两种方式使用同一检测内核，均没有云端报告服务器。

## 自动读取什么

程序只读与网络和 Claude 安装有关的设置：系统和环境代理、代理客户端进程及监听端口、网卡/TUN、路由、DNS、IPv6、时区语言、Claude 安装位置。对支持的本机客户端，还会读取其运行时配置与相关连接证据。它不翻阅私人文档，不读取 Claude Cookie、账号登录态和密码，不自动修复或改系统设置。

识别到的代理入口仍需经过实际请求验证，运行进程名或端口存在不等于代理可用。发现多个候选、权限不足或访问受限时，界面显示证据与限制，不编造结果。

## 结果怎么看

| 状态 | 意义 |
|---|---|
| 已通过 | 对应的有限测试取得有效证据 |
| 需留意 | 已取得信息，但仍有需要理解的限制 |
| 未通过 | 实际观察到冲突或失败，不是因为没填表 |
| 未验证 | 证据不足、权限不足、超时或当前实现不支持 |

没有预期 IP 时，程序报告实际出口及通道间是否一致。它不会把本次观测到的 IP 宣布为你购买的住宅 IP。你可以在高级设置中填入已核验地址，增加与订单出口的比对；这是可选功能。

## 主要检测范围

| 项目 | 实际读取或测试 | 如何理解 |
|---|---|---|
| 系统与客户端 | 操作系统、时区语言、代理进程与配置 | 不因中文语言或某个时区就判账号危险 |
| 代理入口 | 系统/客户端候选与实际连接 | 无需手填；识别失败说明原因 |
| TCP 出口 | Cloudflare trace 与 ipify，经显式代理及系统默认通道分别查询 | 默认通道不跟随应用代理环境变量；实际不一致会指出 |
| TUN 与路由 | 网卡、进程、路由及可取得的运行配置 | 名称相符不代替实际流量证据 |
| Claude 目标 | 固定 Claude/Anthropic 域名的 TLS 证书及主机名校验 | 证明传输连通，不证明账号或资格 |
| DNS | 解析样本和可读取的客户端配置 | fake-IP 不等于无泄漏；不足的证据保持未验证 |
| UDP / STUN | 两个独立目标的出口样本 | 不一致是问题；无响应不能当无泄漏 |
| IPv6 | IPv6 查询目标与本机相关设置 | 额外通道需核对策略；超时不等于已阻断 |
| ASN | 按实际路径查询归属 | 不认证住宅、独享或信誉 |
| Claude 安装 | 自动发现位置并检查客户端身份 | 找到路径与验证签名不同；无法验证时不绕过启动校验 |

住宅 IP 由本人购买仍是本教程的线路选择要求，但“已经购买”的勾选不属于网络证据。程序不会用它限制检测结果。订单、独享性和固定期限通过采购记录核对，见[住宅出口章节](02-buy-residential-ip.md)。

## 可选的高级设置

住宅 IPv4、HTTP/mixed 代理入口、Claude 路径均可留空，由程序自动读取。需要覆盖识别结果时再填，代理 URL 不接受上游账号密码。真实住宅凭据由承担住宅出站的 VPS 或客户端保管，体检程序不接收这些凭据。

保存覆盖设置后重新检测。默认要求关键 TUN 证据；要求 UDP 是按实际用途选择的更严格选项，不能仅为变绿而关闭。更改设置会使旧报告失效。

## 启动与日常使用

打开程序不会自动启动或登录 Claude。关键检查满足后，点击“启动 Claude”会再次检测，并使用本轮发现和验证的安装位置；不拿过期绿色结果启动。

已运行的 Claude 不受此入口控制。程序没有后台防火墙阻断，掉线后不会自动杀进程；启动许可不代表所有项目无风险。主备线路、目标流量与断线行为仍按[验收章](validation.md)验证。

网络变化后点“重新检测”，查看本次实测结果。求助时使用“导出报告”，不要发送原始配置或账号资料。

## 数据与外部请求

可选设置保存在当前用户的 `claude-network-guide/config.json`：Windows 位于 `%LOCALAPPDATA%`，macOS/Linux 位于 `~/.config`。普通结果在进程内存中，不自动上传或保存历史。分享导出会剔除自动识别的私有配置和路径，并遮盖地址；截图与补充文字仍需检查。

第一次自动体检及后续重检/启动检查会访问固定的 Cloudflare、ipify、ipinfo、STUN 和 Anthropic 目标；对方能看到实际请求来源。本机控制接口只读，密钥不进入报告。详细保护见[安全说明](../SECURITY.md)。
