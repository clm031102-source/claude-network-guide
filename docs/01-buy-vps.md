# 01 · 先购买 VPS

[目录](tutorial.md) · [下一章：购买自己的住宅 IP](02-buy-residential-ip.md)

VPS 是你能够管理的远程服务器，负责加密入口、转发、订阅和维护。住宅 IP 是目标网站最后看到的网络出口。**这通常是两件商品，购买普通海外 VPS 不等于购买住宅 IP。**

本项目不放邀请链接，也不把某家商家的旧价格和库存写成长期推荐。先确认线路结构，再比较同样条件的套餐。

## 购买前明确用途

个人网络入口通常先比较 1–2 核、1–2 GB 内存的轻量方案；这是选购起点，不是性能承诺。只运行代理与订阅可先观察资源使用，再决定扩容。打算运行高级 API 转发服务时，额外计算内存、并发和上游成本。

选择部署模块支持的 Ubuntu 22.04+ / Debian 12+；新机器可优先考虑 Ubuntu 24.04 LTS。不要为了跟教程一致而重装已有业务的服务器。

| 要核对 | 向商家确认什么 | 保存什么 |
|---|---|---|
| 机房与线路 | 你常用网络访问该机房的延迟、晚高峰丢包、限速和可测试地址 | 测试时间、网络、结果 |
| 独立公网 IPv4 | 是否独享，是否 NAT，端口是否受限 | 套餐说明及限制 |
| 流量 | 每月额度，按入站 / 出站 / 双向计算，超额后限速还是收费 | 官方计费规则 |
| 系统 | 支持的发行版、重装能力、root 或 sudo 权限 | 选定系统及版本 |
| 端口 | SSH，以及教程需要的 TCP 80、443、2443、2096 是否可用 | 安全组入口 |
| UDP | 是否允许 UDP，是否限速，住宅出口是否也支持 | 明确的协议说明 |
| 救援 | VNC / 串口 / 救援控制台，丢失 SSH 后如何恢复 | 控制台入口 |
| 退款与换 IP | 时限、使用量门槛、是否排除已开通 / 特价订单、换 IP 费用 | 购买时条款与工单 |
| 使用规则 | 是否允许你打算做的个人代理用途 | 当时有效的服务条款 |

“独享 VPS”“原生 IP”“双 ISP”“静态 IP”“住宅 IP”含义不同，不能互相代替。住宅出口的核验方法在下一章。

## 下单顺序

1. 在商家官方域名确认套餐、退款条件与总价，先选能验证需求的短周期。
2. 选择机房和支持的系统。能提交 SSH 公钥时优先用独立公钥；私钥始终留在本机。
3. 开通后核对实例 ID、公网 IP、系统和 SSH 端口；不要只看付款成功页。
4. 从服务商控制台确认 SSH 主机指纹或首次连接提示。不要习惯性跳过主机身份变化告警。
5. 保留后台救援入口，先验证密钥登录，再考虑关闭密码登录。

服务器地址可以放在你自己的记录中；密码和私钥正文不要放进 AI 提示词。使用初始密码时，在本机终端交互输入。
