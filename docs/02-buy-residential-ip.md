# 02 · 必须自己购买固定独享住宅 IP

[目录](tutorial.md) · [上一章](01-buy-vps.md) · [下一章：配置网络](03-network-setup.md)

**本项目要求住宅出口由你本人购买、单独持有，并在使用期间保持固定。** 不使用来路不明的免费代理，不把多人共享的代理池当成独享住宅线路，不以反复更换 IP 代替排障。

这是一项项目配置要求。住宅 IP 不代表未被滥用，不证明付款或使用地区符合平台资格，也无法保证任何账号状态。ASN、WHOIS 和第三方 IP 分类只是证据的一部分。

## 先问清楚六件事

| 项目 | 合格的信息 | 需要继续问的说法 |
|---|---|---|
| 固定 | 购买期间固定同一个 IPv4；重连、续费、故障时是否改变有书面说明 | “会话保持”“粘性 IP”“最多保持几小时” |
| 独享 | 同一时间只分配给你；代理凭据和允许来源由你控制 | “独享端口”“独立账号”“小范围共享” |
| 住宅 / ISP 属性 | IP 对应的 ASN、运营商、分配方式及服务商说明可核对 | 只给一个“住宅评分”或营销标签 |
| 来源 | 服务商说明合法来源、授权使用方式和其可提供的凭据 | 来路不明的个人设备、无来源说明 |
| 协议 | SOCKS5 / HTTP CONNECT / VPN 支持哪些，UDP 与 IPv6 如何处理 | 只说“支持所有软件” |
| 售后 | 换 IP 的触发条件、次数、收费，退款时限和证据要求 | “封了再说”“开通不管” |

尤其要问：**SOCKS5 是否真的提供 UDP ASSOCIATE？** 支持 SOCKS5 TCP 不等于支持 UDP；HTTP CONNECT 代理通常不能直接承担通用 UDP。只有 TCP 的产品仍可用于特定 TCP 场景，但无法照搬“所有 UDP 走住宅出口”的配置。

## 两种正确的线路结构

### A · VPS 本身就有你购买的固定独享住宅出口

```text
电脑 / 手机
    → 加密代理入口（住宅 VPS）
    → 该 VPS 的固定独享住宅公网 IPv4
    → 目标服务
```

你需要拥有可管理的 VPS 和确认过的住宅出口。即使两者在同一个订单，也逐项核验。通过代理访问两个出口查询服务，看到的地址都应是你购买的住宅 IPv4。

### B · 普通 VPS 中转 + 另购固定独享住宅出口

```text
电脑 / 手机
    → 你的 VPS（REALITY 443 / TLS 2443）
    → 你单独购买的住宅代理 / VPN
    → 固定独享住宅公网 IPv4
    → 目标服务
```

VPS 提供入口，住宅代理提供最终出口。目标服务应看到住宅 IP，不能看到 VPS 的机房 IP。两个入口均须转入**同一个**住宅出站；住宅失效时不能自动改成 VPS 直连或本地直连。

购买前确认 VPS 能访问住宅代理地址、住宅服务是否接受 VPS 作为来源，以及支持的认证方式。IP 白名单认证应填 VPS 的出口地址，不是家里的地址；白名单和账号密码应按商家实际机制配置。

> 上游 VPS 模块默认从 VPS 本身出站，不会因为你购买了住宅代理就自动串联。结构 B 必须单独配置住宅出站和路由，并按下一章验收。

## 收货后验收

1. 记录订单承诺的 IP、国家 / 城市、ASN、协议、独享与固定期限。城市地理库有误差，不将城市标签当硬证据。
2. 在两个独立查询来源中比较出口 IP 与归属。若分类不一致，保存差异并向商家索要解释。
3. 在早晚和重连后复测 IP 是否固定；变了先核对套餐是否本来就是轮换池。
4. 使用实际客户端分别验证 TCP 和 UDP。支持声明、连接成功和持续可用是三个不同结果。
5. 在退款窗口内完成延迟、丢包、吞吐与目标服务传输测试；不要用大流量测速耗尽退款允许额度。
6. 换 IP 或退款前保存时间、测试路径和脱敏结果；先读条款，不把第三方“评分不够”当作商家必须退款的依据。

## 给客服的采购询问模板

```text
我希望购买本人独享、长期固定的住宅 / ISP IPv4，用作个人网络出口。
请确认：
1. IP 在购买期间是否固定，是否只分配给我，重连或续费是否会改变？
2. 可否提供 ASN / 运营商 / IP 类型说明，以及合法来源和使用授权说明？
3. 是否允许从我自有的 VPS 连接？支持哪些协议与认证方式？
4. SOCKS5 是否支持 UDP ASSOCIATE？IPv6 如何处理？
5. 端口、带宽、并发、流量计费和用途是否有限制？
6. 分配后无法满足上述条件，换 IP 和退款的期限、费用、证据要求是什么？
```

完成后在检测工作台填写**最终住宅 IPv4**。勾选“已自行购买固定独享住宅 IP”是你的采购确认，不是程序对商家或住宅属性的认证。
