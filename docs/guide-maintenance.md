# 指南与仓库如何保持同步

读者从 [零基础教程](beginner-guide.md)开始；需要离线阅读时下载 [Word 保姆指南](downloads/防封指南_保姆联动版.docx)。Word 每章都有对应的在线链接，最后一章包含完整 AI 接手提示词。

本页供维护者使用。教程不依赖自动下载更新，也不会把读者电脑或服务器资料同步到 GitHub。

## 唯一正文与提示词

- 修改教程内容：编辑 `docs/beginner-guide.md`。
- 修改完整 AI 提示词：编辑 `prompts/带我完成配置.txt`。不要分别手改指南和接手页中的副本。
- 文档生成器 `scripts/build-guide.py` 会同步提示词、章节锚点和在线目录，再生成 Word。
- `docs/guide-version.json` 记录本次版本及正文、提示词、Word 的 SHA-256。Word 还内嵌生成时正文、提示词与引用图片的摘要；内容变化而未重新生成时，收尾校验会拒绝通过。版本变更时，同步在线页与生成器中的版本号、日期。

## 发布步骤

文档生成器需要 Python 与 `python-docx`；这是维护者生成 Word 的依赖，读者启动检测工作台仍不需要额外 Python 包。

1. 修改正文或提示词，检查步骤与当前程序、官方资料一致。
2. 在仓库根目录运行 `python scripts/build-guide.py`。它会生成 `docs/downloads/防封指南_保姆联动版.docx`，并同步在线正文与接手页。
3. 在 Microsoft Word 中打开生成文件，更新整个目录、页码并保存。不要把目录留为空白，也不要直接在 Word 中改正文；正文应回到 Markdown 修改并重新生成。
4. 检查所有页面：每章另起一页，目录可跳转，图表没有越界，最后的完整提示词可以复制。原件截图、真实凭据和个人网络资料不能混入公开文件。
5. 保存并关闭 Word 后运行 `python scripts/build-guide.py --finalize`，更新文档作者信息与最终文件摘要。此命令仅做封装收尾，不代替重新生成或页面检查。
6. 运行 `python scripts/check-project.py`。它检查本地链接、文档与提示词一致性、下载文件摘要、目录字段及外部链接类型；CI 也会执行这一检查。
7. 将正文、提示词、接手页、Word、版本文件及相关入口一起发布到同一个提交，并核对公开下载能打开。

Word 中的章节链接使用固定的 `chapter-01` 等锚点。改章节标题不会改变这些入口；调整章节顺序时，应检查引用是否仍指向预期内容。

自动检查不能证明 Word 全文一定与 Markdown 语义相同，也不能验证真实网络。维护者仍须重新生成、逐页检查，并将线路验收与文档发布分开记录。
