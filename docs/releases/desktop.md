下载 `ClaudeNetworkGuide-Windows-x64.zip`，完整解压，双击 `ClaudeNetworkGuide.exe`。

- 独立 Windows 窗口，无需安装 Python或手动打开网页。
- 打开后自动读取本机相关配置并体检；不再要求填写 IP、端口、Claude 路径和采购声明。
- 显示系统代理、客户端、TUN、路由、DNS及Claude安装证据，并实际测试出口与目标连通性。
- 高级设置只用于可选覆盖；启动Claude前重新检测，未知项目不会变成绿色通过。
- 保姆指南和完整 AI 提示词同步更新，每章都有在线入口。

本程序只读检测，不改系统网络、地区或语言，不读取账号登录态。实测出口不等于住宅/独享认证；不提供后台断线阻断或保号保证。

支持 Windows x64，显示界面需要 Microsoft Edge WebView2。便携包未做商业代码签名，可用随包 `SHA256SUMS.txt` 核对完整性；不要关闭系统防护。其他平台继续使用仓库源码方式。
