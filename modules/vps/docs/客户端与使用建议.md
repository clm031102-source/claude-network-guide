# 客户端与使用建议

## 电脑：Clash Verge Rev

Windows、macOS、Linux 都用 **Clash Verge Rev**：[下载页面](https://github.com/clash-verge-rev/clash-verge-rev/releases)，按自己的系统和 CPU 选安装包。

1. 打开 **订阅**，粘贴登录信息文件里的 **Clash 订阅地址**，保存；
2. 选中刚导入的订阅；
3. 模式选 **规则**；
4. 打开 **虚拟网卡模式**（TUN）。第一次会提示「TUN 模式需要服务模式，请先安装服务」，点「安装服务」，按提示装上（Windows 点「是」，Mac 输入开机密码）。Windows 再点虚拟网卡模式旁边的设置，打开「严格路由」。

为什么不只开系统代理：系统代理只接管浏览器的网页流量（TCP），浏览器 WebRTC 用的 UDP 会直接从本地网络出去，检测网站就能看到你的真实 IP。虚拟网卡模式让所有流量都先进 Clash 再按规则分流：国内网站照样直连，WebRTC 照常可用，只是出口变成你的服务器 IP。「系统代理」开着或关着都可以。

另外两个设置保持默认：不要打开「DNS 覆写」（订阅里已经带了 DNS 配置），不要关「Clash 设置」里的「IPv6」开关（关掉后 IPv6 流量会绕过虚拟网卡）。

已经遇到 WebRTC 泄露，或者想一步步检查有没有泄露，请看 [Clash Verge WebRTC 泄露修复手册](./Clash-Verge-WebRTC泄露修复手册.md)。这份手册可以直接发给 AI 助手，让它照着带你修。

订阅里有两个节点：`名字-Reality` 是主力，`名字-TLS` 是备用。`AUTO-自动切换` 会在主力不通时换到备用。`AI-人工智能` 分组可以单独指定 AI 工具走哪个节点。

常见问题：

- 旧版 Clash for Windows 打不开这份订阅（报 `cannot unmarshal !!seq into string`），换成 Clash Verge Rev。
- Shadowrocket 的订阅地址不能填进 Clash Verge Rev，两者格式不同。

## iPhone：Shadowrocket

添加订阅，粘贴 **Shadowrocket 订阅地址**，更新后选节点即可。

## 路由器：OpenClash

在 OpenClash 里添加 **Clash 订阅地址**。规则文件从你自己的服务器下载，路由器不需要能访问 GitHub。

## 怎么确认通了

打开 <https://ip.net.coffee/claude/>，显示的是你服务器的 IP 和所在地，就说明流量已经走你的线路。

电脑上再打开 <https://browserleaks.com/webrtc>：`RTCPeerConnection` 是 ✔，「Public IP Address」也是你服务器的 IP，就说明 WebRTC 没有泄露。

## 使用习惯

- 长期用同一台服务器时，可以把电脑时区设成服务器所在地，少在不同国家的节点之间来回切。
- 不需要的定位权限可以关掉。
- 遵守当地法律和各个网站、AI 工具的使用规定，不要提交违法或伤害他人的内容。
- 不要用脚本短时间大量刷请求或批量提问，有批量需求请用官方 API。
- 线路只给自己和家人用，不要分享出去。
