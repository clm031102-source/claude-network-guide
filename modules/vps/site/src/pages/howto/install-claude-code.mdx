## 需要什么

- Claude 的 **Pro、Max、Team、Enterprise 或 Console** 账号（免费版不能用 Claude Code）；
- 在 Anthropic 支持的国家和地区使用；
- Mac：macOS 13 以上；Windows：先装好 [WSL](/howto/windows-wsl/)。

## 1. 安装

打开终端（Windows：WSL 里的 Ubuntu），粘贴这条命令，回车：

<Copy id="cc" lang="bash" title="安装 Claude Code（Mac、Linux、WSL）" code="curl -fsSL https://claude.ai/install.sh | bash" />

安装时没有进度显示，等它结束。然后**关掉终端，重新打开**，检查：

<Copy id="cc-v" lang="bash" title="检查版本" code="claude --version" />

能看到版本号（比如 `2.1.211 (Claude Code)`）就装好了。用这种方式安装的 Claude Code 会在后台自动更新。

## 2. 登录

在终端里输入 `claude`，回车。按提示在浏览器里登录你的 Claude 账号，授权后回到终端。

<Callout type="ok">
终端里出现 Claude Code 的对话界面，可以输入问题。
</Callout>

## 卡住了？

<Q q="提示 claude: command not found？">
安装后要重新打开终端。还不行的话，运行 <Cmd c="claude doctor" />（如果能运行）或者查看 [官方安装说明](https://code.claude.com/docs/en/setup) 里的 PATH 设置。
</Q>
<Q q="浏览器没有自动打开？">
终端里会打印一个登录网址，复制到浏览器打开。
</Q>
<Q q="想在 Windows 上不用 WSL 直接装？">
Claude Code 本身支持原生 Windows，但这套方案的脚本需要 Linux 工具，所以本教程统一用 WSL。
</Q>
