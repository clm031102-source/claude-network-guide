## 为什么要改 root 密码

配置完成后，服务器已经**不能用密码远程登录**，只认你电脑上的密钥。但商家后台的救援控制台（VNC / Console）通常还认 root 密码，而这个密码曾经出现在开通邮件、可能还在聊天记录里。改掉更安心。

## 怎么改

- **搬瓦工**：KiwiVM 里的「Root password modification」，会生成一个新的随机密码，抄下来保存好。
- **其他商家**：服务器详情页里找「重置密码」（Reset Password）。
- **或者在服务器上改**：用 `ssh 你的名字` 登录后，输入 `passwd`，按提示输两次新密码（输入时不显示）。

新密码存到密码管理器里，不要发给任何人。

## 救援控制台什么时候用

商家后台里一般叫 VNC、Console、救援控制台（搬瓦工的 KiwiVM 里也有类似的入口）。它相当于直接坐在服务器前面，**不经过 SSH**，所以这些情况能救命：

- 电脑丢了、重装了，密钥没了；
- 改错了 SSH 或防火墙设置，SSH 连不上了。

用 root 和密码登录控制台以后，再找 AI 帮你加一把新电脑的密钥，或者恢复设置。

<Callout type="warn">
在控制台里改 SSH、防火墙设置之前，先想清楚。不确定的话，把屏幕上的提示复制给 AI，让它告诉你该怎么做。
</Callout>
