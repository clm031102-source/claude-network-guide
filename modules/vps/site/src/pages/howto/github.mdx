## 需不需要

**不注册也完全能用这套方案。** 方案仓库和 Clash Verge Rev、FlClash 这些客户端的下载页都是公开的，不登录就能下载。

需要账号的情况：想在方案仓库里提问题（Issue）、给项目点星、或者以后自己存代码。

## 步骤

1. 打开 [github.com/signup](https://github.com/signup)。
2. 填邮箱（推荐 Gmail）、设置密码、起一个用户名（以后会出现在你的主页网址里）。
3. 完成人机验证，邮箱里会收到一个验证码，填进去。
4. 登录后，到 Settings → Password and authentication，打开两步验证（Two-factor authentication）。

<Callout type="ok">
能登录 GitHub，右上角头像能打开你的主页。
</Callout>

## 怎么提问题

打开 [方案的 Issues 页面](https://github.com/clm031102-source/claude-network-guide/issues)，点 New issue，写清楚：做到了第几步、看到了什么提示（文字直接复制，截图要先把 IP、订阅地址、密码打码）、你试过什么。

<Callout type="no">
提问题时不要贴出服务器 IP、密码、订阅地址或 Key。
</Callout>
