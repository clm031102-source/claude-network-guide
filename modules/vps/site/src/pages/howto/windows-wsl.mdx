## 这是什么

<Term k="WSL" /> 是 Windows 自带的一套 Linux 环境。这套方案的脚本需要 bash、ssh 这些 Linux 工具，装好 WSL 以后，Windows 上就能像 Mac 一样直接运行。

要求：Windows 11，或者较新的 Windows 10（2020 年以后更新过的版本）。

## 1. 安装

1. 点开始菜单，搜索「PowerShell」，在「Windows PowerShell」上**右键 → 以管理员身份运行**。
2. 粘贴下面这条命令，回车：

<Copy id="wsl-install" lang="bash" title="在管理员 PowerShell 里运行" code="wsl --install" />

3. 等它下载、安装完成，按提示**重启电脑**。

## 2. 第一次打开 Ubuntu

重启后会自动弹出一个 Ubuntu 窗口（没有的话，在开始菜单里搜「Ubuntu」打开）。第一次会让你：

1. 起一个用户名（英文小写，比如 `me`）；
2. 设置密码，**输入时屏幕上不显示任何字，这是正常的**，输完按回车，再输一次。

这个密码以后执行 `sudo` 命令时要用，记住它。

## 3. 装两个小工具

在 Ubuntu 窗口里运行（会要求输入刚才设的密码）：

<Copy id="wsl-tools" lang="bash" title="在 Ubuntu 窗口里运行" code="sudo apt update && sudo apt install -y git unzip curl" />

<Callout type="ok">
开始菜单里能打开「Ubuntu」，窗口里有一行以 `$` 结尾的字。以后教程里说的「终端」，在 Windows 上就是这个窗口。
</Callout>

## 文件在哪

WSL 里的文件和 Windows 是分开的。在 Ubuntu 窗口里输入 `explorer.exe .`（注意最后有个点），就能用 Windows 的文件管理器打开当前文件夹，比如去找登录信息文件。

## 卡住了？

<Q q="提示需要开启虚拟化？">
重启进 BIOS，打开 Intel VT-x 或 AMD-V（名字因主板而异），再运行一次安装命令。
</Q>
<Q q="wsl --install 只显示帮助信息？">
说明 WSL 已经装过了。在开始菜单里搜「Ubuntu」，没有的话运行 <Cmd c="wsl --install -d Ubuntu" />。
</Q>
<Q q="安装时报 WslRegisterDistribution failed with error: 0xc03a0014？">
意思是 Windows 找不到虚拟磁盘组件，和这套教程无关。按顺序试，每步做完都重启一次：

1. 在管理员 PowerShell 里运行 <Cmd c="wsl --update" />，然后重启电脑。
2. 打开「设备管理器」→「系统设备」，下面这几项如果显示已禁用（图标上有向下的箭头），右键「启用设备」：Microsoft Virtual Disk Enumerator（虚拟磁盘枚举器）、Microsoft Hyper-V Virtualization Infrastructure Driver、Composite Bus Enumerator、UMBus Root Bus Enumerator。一些「系统优化」软件会把它们关掉。
3. 还不行就改用 WSL 1，它不需要虚拟磁盘：在管理员 PowerShell 里依次运行 <Cmd c="wsl --set-default-version 1" /> 和 <Cmd c="wsl --install -d Ubuntu" />。这套方案在 WSL 1 下也能正常使用。
</Q>
