## Why change the root password

After setup, the server **no longer accepts passwords for remote login** — only your computer's key. But the provider's rescue console (VNC / Console) usually still accepts the root password, and that password appeared in the server-ready email and maybe in chat history. Changing it is safer.

## How

- **BandwagonHost**: "Root password modification" in KiwiVM generates a new random password — copy and keep it.
- **Other providers**: look for "Reset Password" on the server page.
- **Or on the server**: log in with `ssh your-name`, type `passwd` and enter the new password twice (nothing shows while typing).

Store the new password in a password manager and never send it to anyone.

## When to use the rescue console

The provider's dashboard usually calls it VNC, Console or rescue console (KiwiVM has a similar entry). It's like sitting in front of the server, **without SSH** — a lifesaver when:

- your computer is lost or reinstalled and the key is gone;
- you broke SSH or firewall settings and can't connect.

Log in to the console as root with the password, then ask AI to help add a new computer's key or restore the settings.

<Callout type="warn">
Think before changing SSH or firewall settings in the console. If unsure, copy the messages on screen to an AI and ask what to do.
</Callout>
