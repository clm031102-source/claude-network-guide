## What it is

<Term k="WSL" /> is a Linux environment built into Windows. This setup's scripts need Linux tools such as bash and ssh; with WSL, Windows can run them just like a Mac.

Requirements: Windows 11, or a reasonably recent Windows 10 (updated since 2020).

## 1. Install

1. Open the Start menu, search for "PowerShell", and on "Windows PowerShell" **right-click → Run as administrator**.
2. Paste this command and press Enter:

<Copy id="wsl-install" lang="bash" title="Run in an administrator PowerShell" code="wsl --install" />

3. Wait for the download and install to finish, then **restart the computer** when prompted.

## 2. Open Ubuntu for the first time

After restarting, an Ubuntu window opens automatically (if not, search the Start menu for "Ubuntu"). The first time it asks you to:

1. choose a username (lowercase English, e.g. `me`);
2. set a password — **nothing shows on screen while typing; that's normal** — press Enter and type it again.

You'll need this password for `sudo` commands later, so remember it.

## 3. Install a few tools

Run this in the Ubuntu window (it asks for the password you just set):

<Copy id="wsl-tools" lang="bash" title="Run in the Ubuntu window" code="sudo apt update && sudo apt install -y git unzip curl" />

<Callout type="ok">
You can open "Ubuntu" from the Start menu, and the window shows a line ending in `$`. From now on, "terminal" in this guide means this window on Windows.
</Callout>

## Where your files are

WSL's files are separate from Windows'. Type `explorer.exe .` (note the final dot) in the Ubuntu window to open the current folder in File Explorer — for example, to find the login-info file.

## Stuck?

<Q q="It says virtualization must be enabled?">
Restart into the BIOS and enable Intel VT-x or AMD-V (names vary by motherboard), then run the install command again.
</Q>
<Q q="wsl --install only prints help text?">
WSL is already installed. Search the Start menu for "Ubuntu"; if it isn't there, run <Cmd c="wsl --install -d Ubuntu" />.
</Q>
<Q q="Install fails with WslRegisterDistribution failed with error: 0xc03a0014?">
Windows can't find its virtual disk support — this isn't caused by the guide. Try these in order, restarting after each:

1. In an administrator PowerShell, run <Cmd c="wsl --update" />, then restart.
2. Open Device Manager → System devices. If any of these are disabled (down-arrow icon), right-click → Enable device: Microsoft Virtual Disk Enumerator, Microsoft Hyper-V Virtualization Infrastructure Driver, Composite Bus Enumerator, UMBus Root Bus Enumerator. Some "system optimizer" tools turn them off.
3. Still failing? Use WSL 1, which needs no virtual disk: in an administrator PowerShell run <Cmd c="wsl --set-default-version 1" />, then <Cmd c="wsl --install -d Ubuntu" />. This setup works fine on WSL 1.
</Q>
