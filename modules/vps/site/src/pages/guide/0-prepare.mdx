## 这一步做什么

读完这一页，你会知道要准备哪些东西、大概花多少钱、一共要多久。这一步不用动手。

## 先认识三个词

整个教程只要先懂这三个词，其他的边做边学。

- **服务器**（<Term k="VPS" />）：在国外机房租的一台电脑，24 小时开着。你看不见它，只能远程操作它。
- **<Term k="节点" />**：你的电脑连到这台服务器的一条加密通道。网站看到的是服务器的 IP，不是你的。
- **<Term k="订阅" />**：一个网址。客户端打开它，就能拿到节点和「哪些网站走服务器」的规则，以后还会自动更新。

## 你需要准备的东西

| 东西 | 用来做什么 | 没有怎么办 |
|---|---|---|
| 一台电脑（Windows 或 Mac） | 配置服务器、装客户端 | 必须有。Windows 要先装 WSL，见 [Windows 安装 WSL](/howto/windows-wsl/) |
| 一种能在国外网站付款的方式 | 买服务器 | 推荐的搬瓦工支持**支付宝**（Alipay），有支付宝就行；其他商家以结账页为准，见 [在国外网站付款](/howto/payment/) |
| 一个能正常收信的邮箱 | 注册服务器账号、收开通邮件 | 推荐 Gmail，见 [注册 Google 邮箱](/howto/gmail/) |
| AI 编程工具（可选） | 让 AI 帮你配置服务器 | 没有也行，第 3 步可以自己照着敲命令 |
| 境外 Apple ID（只有 iPhone 需要） | 下载 Shadowrocket | 中国区商店没有这个 App，见 [注册境外 Apple ID](/howto/apple-id/) |

## 大概花多少钱

- **服务器**：唯一必须花的钱，按季或按年付，价格以商家官网为准。1 核、1G 内存就够用。
- **电脑客户端**：Clash Verge Rev，免费。
- **iPhone 客户端**：Shadowrocket，美区 App Store 一次性付费，大约 3 美元（以商店页为准）。
- **AI 工具**（可选）：Claude Code 需要 Claude 的付费账号，Codex 需要 ChatGPT 的付费账号。不用 AI 路线就不花这笔钱。
- **证书、规则、AI 接口软件**：全部免费。不需要买域名。

## 一共要多久

第一次做大约一个小时，主要花在买服务器和装客户端上。让 AI 配置服务器那一步只要 10 分钟左右。以后再配第二台会快很多。

<Callout type="warn" title="出发前做完">
很多工具在网络受限的地方很难打开，包括 AI 工具、下载客户端的网站，有时连 GitHub 都很慢。所以请在出发前把整套流程做完，并在手机和电脑上都测一遍。
</Callout>

## 两条路线，现在先选一条

- **让 AI 来配（推荐）**：你已经能用 Claude Code 或 Codex。第 3 步只要复制一段话给 AI。
- **自己照着敲**：你还没有 AI 工具。第 3 步会把每条命令列出来，复制、粘贴、回车。

两条路线的结果完全一样，只是第 3 步谁来动手的区别。

<Callout type="no">
不要把服务器的 IP、密码、订阅地址发到群里或截图分享。它们就像家门钥匙，谁拿到谁就能用你的线路。
</Callout>

## 卡住了？

<Q q="我完全不懂电脑命令，能做吗？">
能。AI 路线里，你只需要复制粘贴一段话，再回答 AI 的几个问题。手动路线也是复制命令、粘贴、回车，每一步都会告诉你应该看到什么。
</Q>
<Q q="一台服务器能给几个人用？">
你和家人的多台设备同时用都没问题。不要分享给外人：流量会被用完，别人做的事也算在你的服务器头上，IP 还可能因此被封。
</Q>
<Q q="为什么不直接买现成的「机场」？">
机场是很多人共用一批服务器，便宜、省事。自己的服务器只给你用，IP 不会被陌生人用坏，还能顺便搭一个自己的 AI 接口。两种都可以，这个教程讲的是后一种。
</Q>
