## 这一步做什么

准备好下一步要用的工具：一个能输入命令的<Term k="终端" />，以及（如果走 AI 路线）一个能替你执行命令的 AI 助手。

不管走哪条路线，**终端都要准备**：AI 也是在终端里替你干活的。

## 第一件事：打开终端

<Tabs id="term" label="你的电脑" items={[["mac", "Mac"], ["win", "Windows"]]}>
<div slot="mac">

Mac 自带终端：按 <kbd class="xxd-kbd">⌘</kbd> + <kbd class="xxd-kbd">空格</kbd>，输入「终端」，回车。会出现一个白色或黑色的窗口，里面有一行以 `%` 或 `$` 结尾的字，这就是终端。

</div>
<div slot="win">

这套方案的脚本要在 Linux 环境里运行，Windows 要先装一个自带的 Linux 环境 <Term k="WSL" />，大约 10 分钟，要重启一次电脑。

按 How-to [Windows 安装 WSL](/howto/windows-wsl/) 做完，再回到这里。**以后本教程说的「终端」，在 Windows 上都是指 WSL 里的 Ubuntu 窗口**。

</div>
</Tabs>

<Callout type="tip" title="终端怎么用">
把命令复制进去，按回车，等它跑完。看到一行新的 `$` 或 `%`，就表示这条命令结束了。粘贴密码时屏幕上不会显示任何字，这是正常的。
</Callout>

## 走手动路线的：到这里就够了

不打算用 AI 的话，终端准备好就可以去下一步，选「自己照着敲」。

## 走 AI 路线的：装一个 AI 助手

两个选一个就行。哪个你有账号就装哪个：

| | Claude Code | Codex |
|---|---|---|
| 出自 | Anthropic（Claude） | OpenAI（ChatGPT） |
| 需要的账号 | Claude 的 Pro、Max、Team、Enterprise 或 Console 账号（免费版不行） | ChatGPT 的 Plus、Pro、Business、Edu、Enterprise 等付费账号 |

<Callout type="warn">
这些 AI 服务要在它们支持的国家和地区使用。如果你现在还用不了，就先走手动路线，配好以后再装 AI 助手也不迟。
</Callout>

<Tabs id="ai" label="选一个 AI 助手" items={[["claude", "Claude Code"], ["codex", "Codex"]]}>
<div slot="claude">

在终端里粘贴这条命令，回车（Mac 和 Windows 的 WSL 里都是这一条）：

<Copy id="cc-install" lang="bash" title="安装 Claude Code" code="curl -fsSL https://claude.ai/install.sh | bash" />

装好后**关掉终端再重新打开**，输入下面这条检查一下，看到一个版本号就对了：

<Copy id="cc-ver" lang="bash" title="检查" code="claude --version" />

然后输入 `claude` 回车，按提示在浏览器里登录你的 Claude 账号。详细说明见 [安装 Claude Code](/howto/install-claude-code/)。

</div>
<div slot="codex">

在终端里粘贴这条命令，回车（Mac 和 Windows 的 WSL 里都是这一条）：

<Copy id="cx-install" lang="bash" title="安装 Codex" code="curl -fsSL https://chatgpt.com/codex/install.sh | sh" />

装好后**关掉终端再重新打开**，输入下面这条检查一下，看到一个版本号就对了：

<Copy id="cx-ver" lang="bash" title="检查" code="codex --version" />

然后输入 `codex` 回车，选「Sign in with ChatGPT」，在浏览器里登录你的 ChatGPT 账号。详细说明见 [安装 Codex](/howto/install-codex/)。

</div>
</Tabs>

<Callout type="ok">
输入 `claude` 或 `codex` 能打开 AI 助手，而且已经登录，可以跟它对话。
</Callout>

## 可选：装成 skill

经常配服务器的话，可以把这套方案装成 AI 的 skill，以后一句「用 claude-network-guide 帮我配置新买的服务器」就行。第一次用不装也没关系，下一步的那段话会让 AI 自己去下载方案。见 [安装 claude-network-guide skill](/howto/install-skill/)。

## 卡住了？

<Q q="提示 command not found / 找不到命令？">
装完要关掉终端重新打开，新装的命令才找得到。还不行的话，看对应 How-to 里的说明。
</Q>
<Q q="登录时浏览器没有自动打开？">
终端里会打印一个网址，复制到浏览器里打开，登录后回到终端。
</Q>
<Q q="Windows 能不能不装 WSL，直接在 PowerShell 里用？">
AI 助手本身可以在 Windows 上直接装，但这套方案的脚本需要 bash、ssh 这些 Linux 工具，在 WSL 里最省事，所以统一推荐 WSL。
</Q>
