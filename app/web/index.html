STEP 01 / SERVER

先有一台自己的 VPS.

服务器账户、账单和配置，都由你自己管理。

准备阶段 · 01 / 04
01
建立基础连接

VPS 提供服务器，
住宅 IP 决定最终出口。

购买 VPS 只是第一步。普通云服务器 IP 往往属于数据中心，不能把它直接当成已经购买的住宅 IP。

A

自己开户、自己购买

在服务商官网注册自己的账户，核对地区、系统支持、流量额度、计费方式和退款规则。保存账单与续费日期。

B

确认基础访问

获取服务器地址与连接方式，优先配置 SSH 密钥。先确认能稳定登录，再继续安装网络服务。

C

只开放需要的端口

按实际方案配置防火墙，限制管理入口。不要直接使用来历不明的一键脚本，也不要把管理凭据发给他人。

阅读完整 VPS 购买教程 ↗
STEP 02 / YOUR EXIT IP

住宅 IP，一定要自己购买.

在商家开自己的账户，控制购买、续费和出口的使用权限。

准备阶段 · 02 / 04
02
本项目的采购要求

固定、独享，
住宅或 ISP 类型。

向商家核实是否长期固定、是否仅供你使用、所属 ASN 与网络类型，以及不符描述时的更换或退款政策。

付款前，问清这四件事

  1. 01

    固定性

    续费后能否保留同一 IP？是否会自动轮换？

  2. 02

    独享性

    该出口是否只有你在使用？“专属端口”并不等于独享 IP。

  3. 03

    网络归属

    是住宅或 ISP 网络，还是普通数据中心？第三方标签只作为参考。

  4. 04

    售后与控制权

    能否自行改密码、续费和换 IP？售后规则是否有明确书面说明？

采购归属由你核实。 程序无法自动证明 IP 的独享性、购买归属或账号适用性。这些采购事项只作教程参考，不作为本机体检的填写前提。
阅读完整住宅 IP 教程 ↗
STEP 03 / CONNECTION

让应用走你确认的出口.

先连接，再核实路由。浏览器能打开网页只是其中一项证据。

此图是目标路径。检测结果只能证明实际取得的证据，不能自动证明整条链路。

01

配置本地代理

本机体检会自动识别代理地址。只有自动识别不符合实际时，才在高级设置中指定本地 HTTP 代理。

02

核实 TUN 与 DNS

按方案启用 TUN，确认 DNS、IPv6 与需要的 UDP 流量如何转发。检测不到的能力会保留为“未验证”。

03

再检查应用路径

本机体检会自动查找 Claude 安装位置。启动后仍应通过代理的实际连接记录确认应用使用的出口。
